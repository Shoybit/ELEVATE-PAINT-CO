# Elevate Paint Co.

A modern, responsive painting company website built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Motion**.

## Overview

Elevate Paint Co. is a professional painting service website designed to present residential and commercial painting services, company benefits, project statistics, and quote/contact calls-to-action.

The website includes smooth scroll-based animations and responsive layouts for desktop, tablet, and mobile devices.

## Features

- Responsive modern painting company website
- Hero section with service-focused messaging
- Residential and commercial painting services
- Interior, exterior, and commercial service cards
- Company value propositions
- Project statistics section
- Why Choose Us section
- Free quote call-to-action
- Smooth entrance animations using Motion
- Hover effects and interactive UI elements
- Responsive typography and spacing
- Reusable React components
- TypeScript support
- Vite development and production build setup

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React
- Google GenAI
